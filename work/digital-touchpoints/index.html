The collection

Small interfaces, each with one precise job.

Not every contribution needs the scale of a complete product. These three production touchpoints show how I adapt hierarchy, imagery, calls to action and the Club del Sole brand system to different moments of the guest journey.

The two promotional examples are deliberately cropped to the hero areas I worked on. The Wi-Fi interface is shown in full because the complete access flow was the relevant design object.

Club del Sole · Production UI
01Seasonal campaign

A Valentine’s hero with its own visual identity.

I personalised the main website hero for the Valentine’s period, connecting the Gift Card offer to an emotional campaign language while preserving Club del Sole’s navigation, booking context and brand recognition.

Scope noteMy contribution focused on the promotional hero and its connected offer area; the rest of the homepage is outside the scope shown here.

Club del Sole · Production UI
02Guest utility

A clear Wi-Fi access screen for an immediate task.

The guest arrives with one objective: connect. The interface keeps language selection, email input and the primary CTA in a single central path, while consent and QR-code access remain available without competing with the main action.

Scope noteThe branded access screen was prepared for use across selected Club del Sole villages and supports four visible language options.

Club del Sole · Production UI
03Commercial campaign

An early-booking offer readable in a few seconds.

For the Prenota Prima campaign, I personalised the homepage hero around the −10% offer. The large benefit, deadline and CTA form one compact hierarchy, supported by lifestyle imagery that keeps the message connected to the holiday experience.

Scope noteOnly the campaign hero is presented as my interface work; the rest of the production homepage is intentionally excluded.

Project note · Digital touchpoints

These three small interfaces taught me to change the visual emphasis without changing the brand: one message, one task and one obvious next action each time.
