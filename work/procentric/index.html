The challenge

Turn a generic TV template into a useful resort interface.

Guests interact with an in-room TV from several metres away and navigate with a remote rather than a mouse or touchscreen. The interface therefore needed strong hierarchy, large targets, immediate orientation and short paths to useful resort content.

Starting from LG’s default system template, I independently designed and assembled the Club del Sole interface directly on the Pro:Centric server. I owned the visual structure, colours, imagery, navigation, buttons, page layouts and QR touchpoints; the Content Specialist supplied the editorial copy. The system was then adapted across eight resort portals.

01

10-foot interface

Typography, contrast and navigation had to remain immediately readable from across the room, not only at desktop distance.

02

Remote-first navigation

Every destination needed a predictable focus order, large targets and a clear way back for guests using a TV remote.

03

One system, eight resorts

A repeatable visual structure had to accommodate property imagery, languages and local services without losing brand coherence.

My contribution

From a base template to a scalable TV design system.

  1. 01
    Home-screen architecture

    Rebuilt the information hierarchy around resort identity, language access and a bottom navigation rail that remains readable at TV distance.

  2. 02
    Visual system & brand kit

    Defined colours, imagery, title panels, buttons, spacing and icon treatment to translate Club del Sole’s visual identity into the LG environment.

  3. 03
    Reusable internal-page template

    Created a consistent page system for corporate information, loyalty, take-away, mobility and partner experiences instead of designing isolated screens.

  4. 04
    QR-code journeys

    Connected the passive TV interface to action on the guest’s phone through prominent QR touchpoints and concise CTA framing.

  5. 05
    Direct server implementation

    Designed, assembled and refined the interface directly inside Pro:Centric, validating the real TV output rather than handing off a static mockup.

Internal page system

Different services, one visual grammar.

Each screen changes content, not interaction logic. Large titles, short copy blocks, consistent back controls, image framing and QR calls to action create coherence across first-party and partner journeys.

LG Pro:Centric · Hospitality TV
01Global control

Multilingual access without visual noise.

A central modal reduces the decision to three large, recognisable options. The strong container, generous spacing and single back action keep the state clear when controlled from a distance.

Rollout at scale

A shared system, adapted to eight resort identities.

01

Shared shell

Navigation position, focus logic, typography and page hierarchy stay stable so the experience remains familiar.

02

03

Working directly on the server let me verify real screen proportions and refine the output in its final environment.

Project note · Pro:Centric

Designing for TV made me work in metres instead of pixels: focus order, back controls and QR hand-offs had to succeed before any decorative choice could matter.
